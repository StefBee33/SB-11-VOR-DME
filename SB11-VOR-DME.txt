 ; Program for VOR/DME navigation (aviation)
 ;

 ; Operating conditions:
 ; The calculator must be in DEG mode, not RAD or GRAD (the initialization functions D D' E' ensure that).
 ; Southern latitudes and western longitudes must be negative.
 ; Magnetic declination is positive east and negative west.
 ; DME distances are in nautical miles; height differences are in feet.
 ; The aircraft's magnetic radial is measured FROM the VOR/DME station, not the selected OBS course unless the CDI is centered with a FROM indication.
 ; Before using the program, press E' to initialize it to a well-defined state.

 ; Interface:
 ;
 ; A' = input/output VOR/DME station latitude             (DDDMM.mmmmm)
 ; B' = input/output VOR/DME station longitude            (DDDMM.mmmmm)
 ; C' = input/output VOR/DME station magnetic declination (DDD.ddddddd)
 ;
 ; A = input/output radial (DDD.ddddddd)
 ; B = input/output DME in nautical miles (nm)
 ; C = input/output height above VOR/DME station in feet (ft) - optional, for greater precision
 ;
 ; Prepare for new calculation with different radial, DME or height:
 ; D = switches A B C to input (leaves input values unchanged, useful for changing only selected values)
 ; D' = erases all input values for radial, DME and height, switches A B C to input
 ;
 ; Prepare for new calculation with different VOR/DME station:
 ; E' = erases all inputs values, switches A' B' C' A B C to input
 ;
 ; E = calculate latitude and longitude of the aircraft, switches A' B' C' A B C to output
 ;
 ; Output:
 ; x (current display) = latitude aircraft  (DDDMM.mmmmm)
 ; t (test register)   = longitude aircraft (DDDMM.mmmmm)
 ; register 07         = latitude aircraft  (DDD.ddddddd)
 ; register 08         = longitude aircraft (DDD.ddddddd)
 ; register 09         = corrected radial   (DDD.ddddddd), converted from magnetic to true radial
 ;
 ; Conversion functions DDDMM.mmmmm <=> DDD.ddddddd:
 ; SBR  .  = DDDMM.mmmmm => DDD.ddddddd (to decimal format)
 ; SBR +/- = DDD.ddddddd => DDDMM.mmmmm (to cockpit format)
 ; Output: current display and register 00
  
 ; Registers:
 ; 00 contains the conversion result DDDMM.mmmmm <=> DDD.ddddddd from SBR . and SBR +/-
 ; 01 VOR latitude      (DDDMM.mmmmm)
 ; 02 VOR longitude     (DDDMM.mmmmm)
 ; 03 VOR declination   (DDD.ddddddd)
 ; 04 radial            (DDD.ddddddd)
 ; 05 DME in nm
 ; 06 height in ft
 ; 07 result latitude   (DDD.ddddddd), intermediate distance / 60 * COS( corrected radial )
 ; 08 result longitude  (DDD.ddddddd), intermediate distance / 60 * SIN( corrected radial )
 ; 09 corrected radial  (DDD.ddddddd) (converted from magnetic to true radial)
 ; 10 scratchpad for conversions
